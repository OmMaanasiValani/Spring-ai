The project covers basic concepts of spring AI
1) Simple chat model
2) Using templates to refine prompts effectively.
3) Fine tuning prompts through templates to obtain response from open ai llm in specific format.
4) Suggesting llm to respond based on the response schema provided. Useful for programmatic calls.
5) Letting llm impersonate and respond based on the role it has been provided and leveraging prompt templates.
